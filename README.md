# Sophia Bot Assets 🌸

Dépôt public des assets graphiques pour le bot Discord Persona **Sophia**.

---

## 📁 Contenu du Répertoire

- **`animations/`** : 75 cinématiques animées complètes d'Assaut Général (*All-Out Attack Animations* au format WebP animé).

---

## ⚡ Accès Direct & CDN

Les animations sont distribuées via Fastly / GitHub Raw pour un rendu instantané et sans limite de taille dans les embeds Discord :

```
https://raw.githubusercontent.com/chenetulipe/sophia-assets/main/animations/{NomPersonnage}.webp
```
