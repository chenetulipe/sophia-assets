# Sophia Bot Assets 🌸

Dépôt public des assets graphiques pour le bot Discord Persona **Sophia**.

---

## 📁 Contenu du Répertoire

- **`finish_screens/`** : 144 écrans de fin (*All-Out Attack Finish Screens*) et portraits de combat (*Battle Cut-Ins*) haute définition au format WebP.
- **`animations/`** : 75 cinématiques animées complètes d'Assaut Général (*All-Out Attack Animations*).

---

## ⚡ Accès CDN Mondial (jsDelivr)

Les assets sont distribués via le CDN mondial jsDelivr pour un affichage instantané et fluide dans les embeds Discord :

- **Écran de Fin (Finish Screen)** :
  ```
  https://cdn.jsdelivr.net/gh/chenetulipe/sophia-assets@main/finish_screens/{NomPersonnage}.webp
  ```
- **Portrait de Combat (Battle Cut-in)** :
  ```
  https://cdn.jsdelivr.net/gh/chenetulipe/sophia-assets@main/finish_screens/{NomPersonnage}_Battle.webp
  ```
- **Animation Complète (Cutscene Animée)** :
  ```
  https://cdn.jsdelivr.net/gh/chenetulipe/sophia-assets@main/animations/{NomPersonnage}.webp
  ```
